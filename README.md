# Use Case (Unit 5)

## AI-Based Smart Manufacturing Automation System

### Scenario

The manufacturing industry aims to reduce manual monitoring and improve efficiency through automation. IoT devices and embedded controllers are used to automate machinery, monitor performance, and perform predictive maintenance.

### Target Audience

Manufacturing companies in automotive, electronics, and food processing industries.

### Objectives

* Improve production efficiency by 30%.
* Minimize machine downtime through predictive maintenance.
* Enable real-time monitoring and remote control.
* Reduce energy consumption through process optimization.

---

# Prompt Design

## 1. Comparative Analysis Prompt

### Prompt

**"Compare and contrast traditional manufacturing systems and IoT-based smart manufacturing systems in terms of efficiency, maintenance, monitoring, cost, and energy consumption."**

### Expected Response

| Traditional Manufacturing | Smart Manufacturing    |
| ------------------------- | ---------------------- |
| Manual monitoring         | Automated monitoring   |
| Reactive maintenance      | Predictive maintenance |
| Lower initial cost        | Higher initial cost    |
| More downtime             | Less downtime          |
| Higher energy consumption | Optimized energy usage |

---

## 2. Experiential Perspective Prompt

### Prompt

**"As a manufacturing engineer, describe your experience using an IoT-based smart manufacturing system for predictive maintenance and production monitoring."**

### Expected Response

"As a manufacturing engineer, I can monitor machine health in real time using IoT sensors. Predictive maintenance alerts help prevent machine failures, reducing downtime and improving productivity. Remote monitoring also allows quick decision-making and better resource management."

---

## 3. Everyday Functioning Prompt

### Prompt

**"Explain how IoT technology used in smart manufacturing is similar to smart devices used in everyday life."**

### Expected Response

"Just as a smartwatch tracks health data and sends alerts, IoT sensors in manufacturing machines monitor temperature, vibration, and performance. Both systems collect real-time data and provide notifications to improve efficiency and prevent problems."

---

## 4. Universal Prompt Structure (Prompt Refinement)

### Prompt

**"Explain IoT-based smart manufacturing in simple terms with an example. Also explain the working process step by step."**

### Expected Response

### Simple Explanation

Smart manufacturing uses IoT sensors and controllers to automate machines and monitor production processes.

### Example

A factory machine uses sensors to detect abnormal vibration. Before the machine fails, the system sends an alert to the maintenance team.

### Step-by-Step Process

1. Sensors collect machine data.
2. Data is sent to the cloud/server.
3. AI analyzes machine performance.
4. Potential faults are detected.
5. Alerts are sent to operators.
6. Maintenance is performed before breakdown occurs.

---

## 5. Prompt Size Limitation

### Large Prompt

**"Explain 50 applications of IoT in manufacturing and provide examples."**

### Refined Prompt

**"Explain 10 applications of IoT in manufacturing with examples. Continue with the next 10 applications after completion."**

### Benefit

Breaking large prompts into smaller parts improves response quality, readability, and AI performance.
